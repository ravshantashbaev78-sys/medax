# Medax Mobile — Rasmiy Mobil Ilova (React Native / Expo)

Ushbu ilova Medax tibbiyot uskunalari do'konining Android va iOS uchun mo'ljallangan rasmiy mobil ilovasi.

## Imkoniyatlari:
- 🏥 **Tibbiy uskunalar katalogi**: Kategoriyalar, qidiruv va filtrlash.
- 🛒 **Savatcha va Buyurtma berish**: Oflayn rejimda saqlanuvchi savatcha va backendga to'g'ridan-to'g'ri buyurtma jo'natish.
- ⚡ **Tezkor va zamonaviy UI**: React Navigation va Native komponentlar yordamida silliq ishlash.

## Ishga tushirish (Ishlab chiquvchilar uchun):

```bash
# 1. Mobil ilova papkasiga o'ting:
cd mobile

# 2. Kerakli paketlarni o'rnating:
npm install

# 3. Ilovani ishga tushiring:
npx expo start
```

### Telefonda sinab ko'rish:
1. Telefoningizga **Expo Go** ilovasini yuklab oling (Google Play yoki App Store dan).
2. Terminalda chiqqan QR kodni telefoningiz kamerasi yoki Expo Go orqali skaner qiling.
3. Ilova bir necha soniyada telefoningizda jonli ishga tushadi!
